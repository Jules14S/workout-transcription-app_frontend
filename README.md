# Workout Transcription Frontend

This is the **React frontend** for the Workout Transcription App. It allows users to upload images of their workout logs and receive a structured Excel file generated by the backend.

---

## Features

- Upload one or more workout log images
- Send images to backend via POST
- Download an Excel `.xlsx` file containing:
  - Workout date and title
  - Exercise names
  - Sets, reps, and additional notes

---

## Tech Stack

- **React** – frontend UI framework
- **Axios** – HTTP client to send image data
- **Netlify** – for hosting the frontend
- **HTML + CSS** – base styles and layout

### 1. Clone the Repo

```bash
git clone https://github.com/yourusername/workout-transcription-app_frontend.git
cd workout-transcription-app_frontend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the App

```bash
npm start
```

The app will be available at:
```
http://localhost:3000
```

---

## Connecting to Backend

This app expects the Flask backend to be running at:

```
http://127.0.0.1:5000/
```

Make sure both frontend and backend are running locally at the same time. The frontend will send the uploaded images as a `POST` request to the backend’s root `/` route.

> You can modify the backend address via the `proxy` field in `package.json` or by editing the Axios request in `App.js`.

## Deployment

This app is deployed via **Netlify**.

To deploy yourself:

1. Push your frontend to GitHub
2. Go to [https://app.netlify.com](https://app.netlify.com)
3. Connect your GitHub repo and configure:
   - **Build command**: `npm run build`
   - **Publish directory**: `build`
4. Click **Deploy**

Your app will be hosted at a Netlify-generated URL like:

```
https://your-app-name.netlify.app
```
